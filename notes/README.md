# Notes

Self-contained study notes for PPHA 44100, in Markdown with LaTeX math.

Each file is an **original write-up** synthesizing a chapter — page-by-page, in the
author's own words, drawing on the instructor's notes (Scott Ashworth) and MWG. They are
summaries, not reproductions of the source material.

## Naming

- `Chapter-N-Slug.md` — one file per chapter (e.g. `Chapter-1-Rational-Choice-Theory.md`).

## Ground rules

- Write in your own words, and cite the source inline (instructor-note section, MWG
  chapter) so others can verify.
- Do **not** paste the instructor's notes or textbook text verbatim, and do **not**
  commit the source PDFs — they are copyrighted and live outside this repo.
